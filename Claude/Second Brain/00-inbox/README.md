# 00-inbox

**Capture first, sort later.**

Anything that arrives unprocessed lands here: quick notes, links, voice-memo
transcripts, screenshots, half-formed ideas, things pasted mid-conversation.

Rules of thumb:
- Never block on naming or formatting — just get it in.
- Nothing lives here permanently. Each item eventually gets moved to
  `10-context`, `20-wiki`, `30-projects`, or `40-skills`, or gets deleted.
- Review on a regular cadence (weekly works well) and aim to empty it.

If you're unsure where a note belongs, it belongs here.
