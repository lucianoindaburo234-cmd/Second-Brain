# Second Brain

An Obsidian vault. Open this folder as the vault root.

| Folder | What belongs there |
|---|---|
| [`00-inbox`](00-inbox) | Unprocessed capture — nothing lives here permanently |
| [`10-context`](10-context) | Stable facts about me, my setup, goals and preferences |
| [`20-wiki`](20-wiki) | Evergreen reference knowledge, one topic per note |
| [`30-projects`](30-projects) | Active work with a goal and an end date |
| [`40-skills`](40-skills) | Repeatable procedures written to be executed |
| [`90-meta`](90-meta) | Conventions, templates and upkeep for the vault itself |

Each folder's own README explains what belongs there and what doesn't.
Vault-wide conventions live in [`CLAUDE.md`](CLAUDE.md).
