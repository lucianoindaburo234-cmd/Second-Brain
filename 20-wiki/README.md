# 20-wiki

**Durable reference knowledge, one topic per note.**

Evergreen notes about concepts, tools, techniques, and how-things-work — written
so they're useful the next time the topic comes up, independent of any single
project.

Belongs here:
- Concept and topic notes, distilled in my own words
- How-tos and cheat sheets, definitions, mental models
- Summaries of things I've read or watched, with sources linked

Doesn't belong here:
- Facts about *me* → `10-context`
- Time-boxed work with a deliverable → `30-projects`
- Repeatable procedures meant to be *executed* → `40-skills`

Conventions:
- One idea per note, named after the idea itself.
- Link generously between notes; the links are the value.
- Rewrite rather than pile on — notes should get sharper over time.
