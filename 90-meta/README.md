# 90-meta

**The vault about the vault.**

Notes on how this system is structured and maintained — the stuff that isn't
knowledge, but keeps the knowledge usable.

Belongs here:
- Folder conventions, naming rules, tagging and linking schemes
- Templates for new notes
- Maintenance routines: inbox review, archiving, pruning
- Changelog and decisions about how the vault has evolved
- Configuration and tooling notes for the vault itself

If a note explains how to *use or maintain* this vault, it goes here. If it's
subject-matter knowledge, it goes in `20-wiki`.
