# 40-skills

**Repeatable procedures, written to be executed.**

Instructions for doing a specific kind of task the same way every time — by me
or by an AI assistant. If `20-wiki` is what I know, this is what I (or an agent)
can *do*.

Belongs here:
- Step-by-step workflows, checklists, and runbooks
- Prompt templates and agent instructions
- Scripts and automation, with a note explaining when to run them

Conventions:
- One skill per folder or file, named for the task it performs.
- Start with when to use it, then the steps, then the gotchas.
- Written imperatively — a reader should be able to follow it without context.
- Prune anything that no longer reflects how the task is actually done.
