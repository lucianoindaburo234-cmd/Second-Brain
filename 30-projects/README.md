# 30-projects

**Active work with a goal and an end.**

One folder per project, each with its own notes, tasks, drafts, and artifacts.
A project is anything with a defined outcome and a point at which it's done.

Suggested layout per project:
```
30-projects/<project-name>/
  README.md      # goal, status, next actions, key links
  notes/         # working notes and decisions
  assets/        # drafts, data, files
```

Conventions:
- Each project README states the goal, current status, and the next action.
- When a project finishes, harvest anything reusable into `20-wiki` or
  `40-skills`, then archive the folder.
- Ongoing areas of responsibility with no end date are context, not projects —
  they belong in `10-context`.
